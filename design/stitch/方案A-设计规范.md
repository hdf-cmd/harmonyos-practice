《智题通》鸿蒙原生克制风设计规范（ArkUI 移植指南）

本规范基于已定稿的 12 屏界面设计提炼，完全遵循 HarmonyOS 原生视觉工程理念（克制、高秩序感、无冗余渐变），供 ArkUI 前端研发工程师对照实现。

3. 间距与圆角表 (Spacing & Radius)

ArkUI 推荐按 4vp 网格系统对齐。

项目	规格参数	移植与实现要点

卡片内边距 (Padding)	16vp（紧凑模块取 12vp）	卡片四周均等留白，严禁单侧挤压
卡片纵向间距 (Margin-Bottom)	12vp ~ 14vp	形成规整的节奏感，模块与模块之间取 20vp

主操作按钮高度与圆角	高度 48vp，圆角 12vp	保证大拇指热区，通栏或悬浮固定底栏标准规格
次级按钮高度与圆角	高度 36vp，圆角 8vp	行内重做、查看回顾等轻量操作按钮
分割线规格	粗细 0.5vp ~ 1vp	颜色统一使用 color_border_hairline (#E5E7EB)
4. 阴影规格 (Elevation & Shadows)

克制风核心要求：坚决杜绝大扩散的弥散彩光、深黑投影或毛玻璃滤镜。仅保留 1 档极其微弱的环境灰度悬浮，避免界面出现厚重下坠感。

ArkUI 卡片悬浮属性：
偏移：offset: { x: 0, y: 2 }
模糊半径：radius: 8
投影颜色：#0A000000 (即 4% 透明度的黑色纯净漫反射，近乎不可觉察但卡片与底色自然分离)
非悬浮普通面板：
直接依赖 0.5vp 发丝边框（border({ width: 0.5, color: '#E5E7EB' })）与纯白填充，无投影。
5. 逐屏布局结构 (F01 - F12 结构树)

各屏自上而下对齐顺序与 ArkUI 容器映射，重点标出与常规商业题库 App 的差异：

F01. 登录 (Login)
布局顺序：全屏居中流式布局（Column 居中）。
区块分解：
品牌区域：极简几何 Logo 居中 + 标题“欢迎使用智题通” (22vp Bold) + 副标“华为认证开发者一站式备考平台” (13vp)；
表单卡片 (纯白圆角 16vp)：输入框 1（预填用户名 hdf2026 + 清除图标）、输入框 2（密码 6 点遮蔽 + 眼睛切换）；
提交按钮：通栏主色按钮“登录” (高度 48vp) + 状态提醒小绿点（HarmonyOS 官方考题题库专区已更新）；
底部注册与协议：没有账号？立即注册 + 服务协议居底对齐。
与一般 App 差异：摒弃花哨插画与第三方炫目授权，以华为开发者体系的单点登录严谨风格排版，表单为纯白单卡内聚。
F02. 首页 (Dashboard)
布局顺序：顶栏（智题通 Logo + 搜索 + 头像） → 轮播横幅 → 核心指标卡 → 推荐试卷列表 → 底部三段式导航栏。
区块分解：
轮播公告：平铺式浅底药丸卡片，微小三点指示器（第 2 点激活），文案：47 套模拟卷已更新 · 覆盖 Stage 模型与分布式数据；
统计指标卡：三列等宽数据行（已刷题 142 道 / 考卷完成 8 套 / 模拟均分 74 分），大数字 22vp，无繁复环形图；
推荐试卷：分节标题“推荐试卷”+“全部 >”；单列 3 张试卷卡片，行内结构：卷名居左上，题量/时长/及格线居左下，右侧垂直排列等级胶囊（中级/初级/高级）与分数标签（最好 78 分 / 未考 / 最好 55 分）；
底部导航栏：固定高 56vp，首页 / 刷题 / 我的 三段文字胶囊，当前 首页 高亮。
与一般 App 差异：去电商化促销弹窗与金币任务，只有纯净的刷题进展与试卷信息。
F03. 考试科目 (Subject Grid)
布局顺序：顶栏（“考试科目”+ 搜索 + 头像） → 页面主标与科目统计徽标 → 搜索栏 → 顶部胶囊标签筛选横滑条 → 2 列网格科目卡片 → 底部数据同步提醒条 → 底部导航栏（刷题 激活）。
区块分解：
搜索框：内凹圆角 12vp 容器，带搜索图标与暗字占位；
分类筛选胶囊：横向单选，当前 全部科目 蓝底白字激活；
2 列网格（Grid(columnsTemplate: '1fr 1fr')）：6 个科目方卡，每个卡片左上图标容器，右上属性标签（推荐/必考/高频/强化/专精/全真），中间科目名称，下方题套数，底部文字外加“进入练习 →”链接对齐；
底部提醒：发丝框卡片，带齿轮图标与说明“模拟真题定期同步”。
与一般 App 差异：双列网格强调科目层级与属性归属（如“专精”、“高频”），而非采用扁平单列长列表。
F04. 考卷列表 (Paper List)
布局顺序：导航条（返回键 + 卷包标题“鸿蒙应用开发” + 头像） → 列表状态栏 → 状态胶囊筛选器（全部/未考/已及格） → 单列 5 套试卷卡片 → 底部官方题库信任标。
区块分解：
筛选状态条：左侧“题库进度 · 共 5 套考卷”，右侧“综合排序”图标按钮；
5 张单列卡片（List）：内部信息结构高度标准化——等级标签（中级/高级）+ 试卷名，次行题量/时长/及格线，底行已考次数（已考 2/3 次）与右侧主动作入口（“进入自测 >”、“再次刷题 >”、“开始考试 >”），右上侧对齐最高分或未考标签。
与一般 App 差异：严格显式标出及格分底线与剩余限制次数，突出专业认证考试的规则约束。
F05. 答题页 (Exam Interface)
布局顺序：顶栏（返回 + 卷名 + 头像） → 防作弊告警横条 → 试卷元信息与倒计时栏 → 进度条 → 题型与题目标签行 → 题干区 → 多选选项组 → 底部系统防截屏提示 → 操作控制栏 → 底部主操作按钮。
区块分解：
防作弊警戒横条：浅红底+红字，警示盾牌图标，常驻显示 检测到切出应用，已记录 2 次，请专心作答；
考试头部：试卷名称 + 倒计时钟表 00:37:12；
进度指示：第 7 题 / 共 25 题（数字 7 主色强调） + 蓝色纤细进度条；
题目卡片：多选题胶囊标签 + “标记”图标；题目文字；4 个选项卡（多选框圆角矩形，A 与 C 激活为蓝底白勾，选项卡为浅蓝微描边高亮态，B 与 D 为未选中灰框）；
底部双行固定区：
行 1：系统按键已锁定弱提示；
行 2（横向 Row 均分）：上一题 / 已存疑（橙色激活图标与字） / 答题卡（网格图标） / 下一题；
行 3：通栏大按钮“提交试卷”（高度 48vp 蓝底白字）。
与一般 App 差异：防作弊常驻告警条 + 强制全屏防切屏提示 + 底部存疑状态直接双向绑定，具备严苛的考场感知力。
F06. 答题卡 (Answer Sheet Overlay)
布局顺序：全屏半透明遮罩背景 + 底部向上滑动展开的纯白圆角抽屉（Bottom Sheet）。
区块分解：
抽屉手柄条（居中灰色小药丸线）；
标题栏：左侧图标+“答题卡”大字，右侧带圆形轻量关闭按钮（“×”）；
图例栏：单行水平排列“● 绿色已答 · ● 橙色存疑 · ▢ 蓝框当前题”，右侧“点击跳转”；
25 题网格矩阵（Grid(columnsTemplate: 'repeat(6, 1fr)')）：方块尺寸均等，圆角 8vp。已答题呈现极浅绿底绿字；存疑题右上角有橙色实心小圆点且底色微黄；第 7 题同时具备存疑底色与高亮蓝框描边；未答题呈中性浅灰底；
底部状态汇总行：左侧答题进度 已答 19 / 25，右侧倒计时 剩余 00:37:12；
双按钮操作组：左侧次按钮“继续作答”（占 40% 宽，灰底黑字），右侧主按钮“提交试卷”（占 60% 宽，蓝底白字）。
与一般 App 差异：支持“当前题 + 存疑”复合状态渲染（蓝边框+橙色角标点），点击任一题目直接即时寻址定位。
F07. 答题结果（通过态）(Pass Result)
布局顺序：导航条（返回 + 标题“答题结果” + 头像） → 成绩主得分卡片 → 切屏违规留痕条 → 电子证书凭证提示栏 → 智能解析 AI 入口 → 题目作答分布微缩网格 → 底部固定双按钮。
区块分解：
成绩卡片：绿色“✔ 通过”药丸徽标，中央超大数字 78 分 (36vp Bold 蓝色)，下方居中元数据说明：及格线 60 分 · 用时 32 分 14 秒 · 手动交卷；
违规留痕横条：中性发丝框卡片，带盾牌图标 切出应用 2 次，已由服务端记录；
证书通知条：浅蓝渐隐纯色底卡片，文字“已生成电子证书，可在个人中心查看”并带右箭头；
AI 助教入口：带星芒图标的卡片，右侧内嵌主色胶囊“< 问问 AI 助教”；
25 题微缩分布图：标题“题目作答分布 (共 25 题)”，图例（答对 18 / 答错 5 / 未答 2），6 列微缩圆角矩阵，绿色块、粉红块、浅灰块直观陈列；
底部双按钮：左白底描边按钮“查看回顾”，右蓝底填充按钮“重新刷题”。
与一般 App 差异：不设花哨的放烟花动画或营销裂变分享弹窗，将“防作弊留痕”与“官方证书链路”作为最高级视觉凭证。
F08. 逐题回顾精讲 (Review Detail)
布局顺序：导航条（返回 + 标题“逐题回顾精讲” + 头像） → 卷面概要复盘卡 → “只看错题”过滤行 → 题解卡片流（错题卡 + 对题卡） → 悬浮右下角 AI 助教胶囊。
区块分解：
卷面概要：卷名、通过状态、得分 78 / 100、答对题数 18 / 25；
筛选行：漏斗图标 + “只看错题”文本 + 右侧 ArkUI 原生滑动开关 (Toggle({ type: ToggleType.Switch })，当前置开)；
题解卡片结构（核心工艺）：
左侧状态轨 (Status Rail)：卡片最左沿一条 4vp 宽垂直色条（红色代表答错，绿色代表答对）；
卡片头：题目序号、题型、得分（如：第 3 题 · 单选题 · 0 / 4 分），右上角红字标签“答错”；
题干与选项列表：选项 A 标出浅粉底+“我的选择”红标签；选项 B 标出浅绿底+“正确答案”绿标签；
答案对照行：双行直观对比（我的答案 A / 正确答案 B）；
考点解析盒子：内嵌浅灰圆角容器，图书图标 +“考点解析”小标题 + 深度解题理由；
浮动操作按钮：右下角常驻胶囊型纯蓝按钮“问问 AI 助教”。
与一般 App 差异：采用左侧状态轨（Status Rail）作为正误视觉锚点，选项内直观比对错选与正解，杜绝折叠隐藏，信息密度高度规整。
F09. 我的 (Profile)
布局顺序：顶栏（“个人中心”+ 搜索 + 头像） → 个人信息卡 → 学习数据指标卡 → 功能导航菜单组 → 系统设置卡 → 退出登录按钮 → 底部三段式导航栏（我的 激活）。
区块分解：
开发者个人卡：左侧圆形头像，中央用户工号 hdf2026 + 备考目标签名，带认证认证小胶囊“华为开发者认证学员”，右侧编辑小笔图标；
学习指标栏：三列均分统计（累计刷题 1,420 / 正确率 88.5% / 打卡连胜 26 天）；
核心功能菜单卡（List 带分割线）：考试记录、我的证书（带“2 张 >”徽标）、AI 备考助教（带“● 24h 在线”蓝胶囊）；
系统偏好设置卡：字号大小切换器（右侧内嵌分段控制器：“小 / 标准(高亮) / 大”）、关于智题通（带版本号 v4.2.0）；
底部危险操作区：通栏纯白卡片，红字居中图标“退出登录”；
底部导航栏：固定高 56vp，我的 激活。
与一般 App 差异：突出华为开发者学员认证资质与在线助教，设置项收敛至官方原生常用的极简分段开关。
F10. 考试记录 (History Logs)
布局顺序：导航条（返回 + 标题“考试记录” + 头像） → 测评指标汇总卡 → 4 场历史记录卡片流 → 底部加载更多触发线。
区块分解：
汇总卡片：双列对比栏，左列“累计测评场次 4 次提交”，右列“整体合格率 50% (2 / 4 达标)”；
考试记录项（4 个标准卡片）：
头部：考试卷名，右上角“通过”蓝胶囊或“未通过”粉红胶囊；
次行：提交时间（年-月-日 时:分）；
底行：交卷状态与耗时（如：手动交卷 · 用时 28 分 05 秒 或 超时自动交卷 · 用时 60 分 00 秒），右侧粗体大分值（88 分、78 分、55 分、46 分）；
底部加载行：居中轻灰色“加载更多…”。
与一般 App 差异：清晰标注“手动交卷”与“超时自动交卷”的技术审计区分，保障认证可信回溯。
F11. 我的证书 (Certificates)
布局顺序：导航条（返回 + 标题“我的证书” + 头像） → 官方凭证背书提示条 → 证书卡片列表（有效证书 + 过期证书） → 底部防伪链上核验防伪说明。
区块分解：
背书横条：盾牌图标 + “官方认证电子凭证：华为开发者技术认证官方电子凭证”；
有效证书卡片：顶部证书徽标 + 证书全称（如：HarmonyOS 应用开发 · 中级认证），右上角绿胶囊“● 有效”；网格排列“证书编号、颁发日期、到期日期”；底部通栏主色操作按钮“查看电子证书 / 下载 PDF”；
过期证书卡片：同构卡片，右上角灰胶囊“● 已过期”；底部带旋转刷新图标的白底次按钮“重新认证考试”；
底部权威说明：双向哈希防伪标语“智题通 × 华为开发者技术认证系统同步，电子凭证具备唯一哈希校验码”。
与一般 App 差异：证书数据按照国家及企业认证标准，包含唯一的编号编码与有效期生命周期管理，支持一键下载电子凭证。
F12. 状态补充 (System States Spec)
布局顺序：导航条（返回 + 标题“状态补充” + 头像） → 规范说明副标 → 区块 A（考试未及格状态） → 区块 B（科目缺考空态） → 区块 C（安全退出与会话拦截态） → 引擎版权居底。
区块分解：
状态 A（未及格）：卡片标出红胶囊“● 未通过”，大分值 46 分，细进度条在 46% 处截断并呈现红色；底部提供双按钮：“查看解析”与主色“重新刷题”；
状态 B（空态）：浅灰内凹无边卡片，中性线性文档图标居中，标题“该科目暂无考卷”，说明文字“通过考试即可获得证书”，底端带轻量问号链接“查看排考规则指引”；
状态 C（会话失效拦截）：粉红浅底告警框，挂锁时钟图标，标题“登录已过期，请重新登录”，副文本说明安全原因“为保证答卷及成绩认证安全，超时未操作将自动断开加密通道”，底部配强引导按钮“重新登录”；
底部标准标识：“智题通安全防护引擎 · 遵循 HarmonyOS 统一认证标准”。
与一般 App 差异：在单屏中建立标准的状态容器模型（Fail、Empty、Unauthorized），供全局异常拦截和全局路由守护复用。
