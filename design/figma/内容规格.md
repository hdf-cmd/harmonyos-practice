# 智题通 · 设计稿共享内容规格（三套必须逐字一致）

三套设计稿共用下面这份内容与示例数据。任何文案、数字、字段顺序都不许改——比稿只比设计语言，
不能让某一套因为"内容写得少"看起来更好。

## 画布与产出约定

- 每帧一个手机屏：**390 × 844 px**，圆角外框自定，内容不得溢出（文字不许被裁切）。
- 每帧上方一个标签：`F01 登录 / 注册` 这样的短标题（真实 DOM 节点，不许用伪元素）。
- 每帧包含顶部状态栏（左 `9:41`，右侧信号/Wi-Fi/电量三个小图形，用真实元素或内联 SVG）与底部 Home 指示条。
- 12 帧按 F01→F12 顺序排列，整页用 flex-wrap 网格（帧间距 40px，行间距 64px），页面底色中性。
- 技术约束：单个 HTML 文件、`<style>` 内联、**无 JS、无外链字体、无外部图片**（图标一律内联 SVG 或 CSS 图形）。
- 关键：Figma 导入插件会丢弃 `::before/::after` 的生成内容——所有文字必须是真实 DOM 文本节点。
- 少用 `backdrop-filter`/CSS mask（导入会退化成位图，图层不可编辑）。阴影、渐变可用。
- 字体栈统一写 `font-family: 'PingFang SC','Noto Sans SC','Microsoft YaHei',sans-serif;`（数字/时间等可用等宽栈）。
